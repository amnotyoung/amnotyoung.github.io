02 / LEARNING PATHS

무엇을 배우게 되나요?

강의는 달라도 배움은 하나의 업무 흐름으로 이어집니다.

  1. 01

    시작하기

    채팅을 넘어 프로젝트 폴더와 파일을 중심으로 AI와 협업합니다.

    환경 · 파일 · 프롬프트
  2. 02

    연결하기

    MCP와 외부 도구를 연결해 규정, 법령, 문서, 회의록을 활용합니다.

    MCP · 문서 · 데이터
  3. 03

    축적하기

    Git과 GitHub, Wiki를 이용해 결과뿐 아니라 과정과 지식을 남깁니다.

    Git · GitHub · Wiki
  4. 04

    재사용하기

    반복 업무를 Skill과 Plugin으로 만들고 동료와 안전하게 공유합니다.

    Skill · Plugin · Web

03 / ABOUT

완성된 자료보다
계속 자라는 아카이브
