텍스트 우선

AI에게는 md · csv · json · html로 — 그리고 세상도 텍스트로 가고 있습니다.

M2 · 텍스트 우선
왜 텍스트인가

관건은 정확도가 아니라 '예측 · 검증'입니다.

  • 요즘 AI는 깨끗한 엑셀은 곧잘 읽습니다 — 문제는 '깨끗한지'를 보장 못 하는 것
  • 숨은 시트 · 병합 · 수식 처리에 따라 될 때도, 안 될 때도 — 받은 쪽은 뭘 읽었는지 모릅니다
  • 게다가 토큰 ↑(비용 · 속도), csv · md와 달리 diff도 안 됩니다
M2 · 텍스트 우선
텍스트라고 다 같은 텍스트가 아닙니다

AI가 그대로 읽는 '텍스트 가족'.

글 · 문서

txt 메모 · md 서식 있는 글 · html 웹(이 슬라이드도)

표 · 데이터

csv · tsv 표(엑셀 붙여넣기) · json · xml 데이터 · 설정

공통점 — 사람도 AI도 그대로 읽고, git으로 diff됩니다. (설정 yaml · 소스코드 .py · .sql도 다 텍스트)
반전: docx · xlsx · pptx도 실은 압축된 xml 묶음 — 다만 우리가 직접 못 열 뿐입니다.
M2 · 텍스트 우선
같은 한 줄, 옷만 다릅니다

텍스트 파일, 이렇게 생겼습니다.

csv

품목,수량,단가
라이선스,10,170

json

{ "품목":"라이선스",
  "수량":10, "단가":170 }

xml

<항목 품목="라이선스"
      수량="10"/>

md

## 견적
- 라이선스 ×10 = 170

yaml

품목: 라이선스
수량: 10

html

<tr><td>라이선스</td>
<td>10</td></tr>
모두 같은 정보(라이선스 10개 · 단가 170) — 사람도 열어 읽고, AI도 그대로 먹고, git으로 diff됩니다.

모델에 전달되는 형태토큰csv 대비

xlsx — 표만 추출(보이는 시트)9173.7배
xlsx — 숨은 시트·수식까지1,0044.1배
xlsx — 워크시트 XML 원본4,70719배
xlsx — 파일 원본(XML 전체)10,41842배
② 준비 시간 — 읽어 텍스트로
파일을 읽어 텍스트화중앙값csv 대비
csv read_csv0.15 ms1배
xlsx openpyxl 로드5.16 ms35배

그런데 금액·합계는 xlsx에 숫자로 없습니다(수식만·11칸 빈 값) — 무엇을 근거로 답하는지 안 보임. 숨김 '메모'엔 협상 하한 기밀까지.

'자의성'을 우리 말로

같은 걸 시켜도, 매번 다르게 나옵니다.

그 들쭉날쭉함이 '산포' — AI의 자의성입니다. 혼자면 OK, 남이 이어받는 업무에선 산포가 곧 사고.
산포 관리 — 품질과 운영을 다루는 조직이 익숙한 일.

산포를 줄이는 4대 장치

이 배경에서 Claude Code가 떴습니다.

  • 코드화 — 지침을 텍스트로 명문화 (CLAUDE.md = AI에게 주는 작업표준서)
  • 하네스 — AI를 위한 지그 · 치구, 같은 결과를 보장
  • MCP(Model Context Protocol) — AI를 외부 데이터 · 도구에 표준으로 연결, 추측 대신 실데이터를 조회
  • 스킬 — 검증된 절차를 재사용 · 공유
지그 · 치구 = 부품을 늘 같은 위치로 고정 · 안내해, 누가 만들어도 똑같이 나오게 하는 생산현장 장치.

무대 · 가상 제품 협업 저장소

수행이 관리하고, 고객 대응이 제안하고, 시장이 되돌린다.

제품 기능명세(수행 관리) → 고객 대응이 정본에 근거해 제안한다
→ 못 채우는 요구는 issue로 → 수행 · 운영 지원이 검토
→ 결정 반영 → release 태그로 확정 → 다시 고객 대응으로
'다들 이미 이렇게 한다'가 아니라 '이렇게 갈 수 있다' — 개발팀은 이미 이 방식이고(GitLab은 회사 핸드북 전체를 공개 git으로 운영), AI가 리뷰 부담을 낮춘 지금 다른 기능도 합류할 수 있습니다.
실증 — GitLab 핸드북은 공개 git 저장소로 운영: gitlab.com/gitlab-com/content-sites/handbook (읽는 사이트는 handbook.gitlab.com)

시작 전에 · 딱 한 번 짚고 갑니다

오늘은 가상이라 공개, 실무는 격리합니다.

  • 공개 실습에는 가상 데이터만 사용 — 그래서 안전하게 실습합니다
  • 실무라면 private 저장소 + 조직 접근권한(초대된 사람만)
  • .gitignore — 가격 · 마진 · 개인정보처럼 공유하지 않을 자료는 저장소에 아예 안 올립니다
공개 예시와 실습에 올리는 것은 가상 요구 · 가상 코멘트뿐 — 실제 매출 · 단가는 넣지 않습니다.
